# 不思議なスライム大冒険

Three.js製の3Dスライム討伐RPGブラウザゲームです。
ホーム広場を拠点に、花摘み・釣り・料理・クエスト・ガチャなどのやり込み要素と、
全3章14ステージのボス討伐バトルを楽しめます。

## 遊び方

1. このフォルダごと展開する（またはリポジトリをクローンする）
2. `index.html` をブラウザで開く
3. タイトル画面でスタート

ネットワーク接続はThree.js本体の読み込み（CDN経由）とセーブデータ同期に使用します。

セーブAPIを使う場合は、バックエンドの環境変数`FRONTEND_ORIGIN`に公開フロントエンドのOriginを設定してください。

## 操作方法

**PC**
| キー | 動作 |
|---|---|
| WASD / 矢印キー | 移動 |
| Space / Enter | 攻撃・決定 |
| Q | スキル |
| F | 必殺技 |
| Shift / E | 回避 |
| Esc | 各種画面（商店・ガチャ・きせかえ・ステージ選択・サブエリア等）を閉じる |

**スマホ・タブレット**
画面下の仮想パッドと各アクションボタンで操作します。

## ゲームの流れ

- **Chapter 1：はじまりの草原**（Stage1〜6） - ぷちスライム・ポヨ〜古王スライム・ガガントス
- **Chapter 2**（Stage7〜11） - 異形のモンスター5体
- **Chapter 3：氷結の秘境**（Stage12〜14） - 結晶・氷雪モンスター3体

各ステージ開始時に「強撃」「疾風」「集中」「守護」「会心」「再起」などのビルドを1つ選んで挑みます。
バトルは通常攻撃・スキル・必殺技の3層構成で、回避も駆使して戦います。

## ホーム広場（探索パート）

Animal Crossing風のホーム拠点を、ミニマップ＋ワープ機能を使いながら自由に歩き回れます。

- **花摘み** / **釣り**：タイミング系のミニゲーム。釣りでは小魚・きれいな石・水草・小さなカメなどをレアリティ付きで入手
- **料理**：釣った素材でレシピを作成（クエスト報酬で新レシピが解放されていく）
- **クエスト**：NPCから依頼を受注し、素材集めの目標を達成すると装備品やレシピが手に入る
- **ガイドNPC「ガイドスライム」**：広場での案内役

## コレクション・ガチャ

- 全11種のコスチューム（レア度★1〜3）。専用スキル（キングウェーブ／アイスニードル／サンダーボルト／スピアラッシュ等）を持つものもあり、それぞれスキルのクールダウンが異なる
- ガチャで入手し、図鑑ビューで収集状況を確認できる

## その他の機能

- 初回チュートリアル画面 + ハンズオンの戦闘チュートリアル
- ステージ・広場の状況に応じたBGM切り替え、効果音演出

├── index.html         … 画面のHTML構造

├── fishing.js / flower.js    … 釣り・花摘みミニゲーム
├── cooking.js          … 料理システム
├── quest.js            … クエストシステム
├── home_npcs.js / plaza_guide.js … 広場NPC・ガイド
├── tutorial.js         … チュートリアル
├── timing_ring.js      … タイミング判定リング（釣り等で使用）

## 技術スタック

- Three.js r128（CDN経由）
- Vanilla JavaScript（フレームワーク不使用）
- HTML / CSS / JS のみで完結（フロントエンド単体でも動作可能）

## 既知の制約・今後の改善候補

- カメラはプレイヤーの背後に固定。スマホでの視点回転（スワイプ操作）は未対応
- 複数プレイヤーの同時参加・同期は未実装（現状は1人プレイのみ）
